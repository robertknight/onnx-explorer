# AI Policy

AI may be used to write code in this project, but must not be used to write
comments in issues or pull requests.

If you are opening an issue, you should describe the problem in your own words.
If you are opening a pull request, you must explain the proposed changes in your
own words. As an exception, AI may be used for translation of human-written text
into English.

If you wish to include context from an interaction with AI in your comments, it
must be in a quote or `<details>` block.
